# 工件表面缺陷检测 demo

## 解决什么问题

用传统图像处理找出金属工件表面的凹坑和划痕，不依赖深度学习，
在普通笔记本上就能跑。适用于没有 GPU、也没有标注数据的小批量场景。

## 怎么跑

​```
pip install -r requirements.txt
python detect_defects.py
​```
